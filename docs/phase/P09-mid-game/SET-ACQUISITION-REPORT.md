## Scope and evidence

The five-game loot synthesis and Blizzard's historical staged chapter gifts support earned, class-specific rewards. Their timing is not copied: Hearthfall's existing Sealed Brine and Lockglass Heart milestones provide optional shoulders and feet from the character's original class set. These are two distinct pieces, enough to activate the existing two-piece build effect. Existing story XP, weapon rewards, random drops and saved claimed quests remain unchanged. No new set or six-piece power was invented for this checkpoint.

The server reserves each current-level, non-Ancient, bound piece once. Reconnects retain that reservation; full bags defer custody transfer; a successful claim cannot be repeated. Existing binding metadata is retained, not a new account/trading permission system. All three classes use their actual existing combat modifiers. Removing gear removes its set count.

Ordinary physical vendor stock now scales through50, retaining the researched twelve-normal-kill expected-gold price formula and anti-recycling provenance. Four field contacts sell stock along the new route. Stock revision2 invalidates stale open offers without changing already owned items.
