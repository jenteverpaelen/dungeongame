# Reusable authored-content checklist — C091

Each new zone/family/boss/quest unit must record evidence before design, implementation, removal effects and actual acceptance separately. This is the production checklist used for the six-area early campaign, not a claim that its human gate passed.

| Unit | Required authoring and verification |
|---|---|
| Zone | Stable ID, real band, story prerequisite and legacy-access policy; original ground polygons, paths, footprint-linked structures/props, clear entry/return/onward routes, landmarks; server/client collision; reachable objectives/spawns/NPC approaches validated; world/area/minimap entry; bounded ambient motion and positional audio; gameplay-size screenshot |
| Family | Original silhouette/rig/palette within existing style, roster budget provenance, meaningful behavior change, explicit warning/aim/impact/cancel behavior, bestiary description and habitat; test the distinguishing authority behavior; inspect idle/move/attack gallery. Reusing a rig is not a new family |
| Boss | Original identity, inherited stat budget, mechanics/phase schedule, cover/dodge/death/leash behavior, bounded effects and no accidental summoned loot; real objective credit and a return path; live player feel remains owner acceptance |
| Quest chain | Original offer/objectives/records/completion, physical start/finish, exact authored targets, flags/gates, fixed reward budget, full-bag/retry/save behavior, no replay/backpay of claimed records; journal navigation and clear next destination |
| Item set | Distinct original theme/build purpose, existing stat/affix budgets, legal slots/class limits, generation and equip/set bonuses, preview, ownership/binding and salvage behavior. C091 adds no new item set; existing three sets remain |
| Evidence/cost | Record data counts, changed-file checkpoint, real checks/defects, screenshots and what remains unverified. Do not fabricate owner minutes, elapsed authoring time or independent review from chat activity |
