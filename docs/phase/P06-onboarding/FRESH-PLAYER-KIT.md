# P6 fresh-player kit

C088,2026-10-10. Owner will playtest; no results or threshold approvals are invented here. This kit is ready to use later, not a request to interrupt implementation.

## Consent and setup

Tell the participant: “We are checking whether Hearthfall explains itself. You may stop or skip anything. With your permission we can record anonymous action timings locally in this browser. Nothing uploads automatically. We can inspect or delete these records together. Recording gameplay/video needs separate permission.” Do not record names, chat or account data in the report.

Use a new isolated character/save environment; choose any of the three classes. Record the Git commit separately in the facilitator notes: the export records protocol version, not the exact commit. Use normal combat for human balance observations. Infinite HP is only for an explicitly labelled assisted/scripted walkthrough, never evidence of safety or difficulty. Start Help → Playtest timings → Human playtest only after consent. Clock starts there, not on the creation screen. Reload/disconnect ends it. Record interruptions separately.

## Comprehension and accessibility

Ask in the participant’s own words: what attacks automatically; how position/dash help; how to inspect/equip; what a tier/rune changes; where to find the next objective; why a service needs its physical contact; how to skip/resume/help. For each mark independent explanation / prompted explanation / not understood, with a short anonymous quote if consented. Do not turn this into an arbitrary pass score.

Check keyboard-only lesson/topic/page selection, current remapped labels, readable focus and selected-state text, no timed dismissal, no scrolling content menus, and the existing reduced-flash/shake options. Note clipping or confusing page boundaries. Check returning/skip paths without forcing enrollment.
