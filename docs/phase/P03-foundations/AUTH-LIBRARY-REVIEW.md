## Version and licence boundaries

[Better Auth release page](https://github.com/better-auth/better-auth/releases) identifies v1.7.7 (`db02f23`, Sep30) and reports fixes involving Magic Link takeover, OAuth Proxy and conditional verification consumption. Those specific features are not currently installed in Hearthfall. A fix note is evidence for version/advisory review, not a blanket conclusion that the library is unsafe or now vulnerability-free. Full advisory and dependency review remain pending. Live docs display1.7.7; an eventual experiment must pin all versions and inspect actual package behavior.

[express-session releases](https://github.com/expressjs/session/releases) shows v1.19.0 (`c10b2a3`). Its live documentation contains a1.19.1 path-matching note as well as a1.19.0 header; do not assume every sentence describes the pinned release. Read the complete [v1.19.0 MIT licence](https://raw.githubusercontent.com/expressjs/session/v1.19.0/LICENSE): commercial use permitted subject to preserving notices; no warranty. This covers that component text only, not its dependency tree. Better Auth licence endpoints failed retrieval in this pass, so its licence is **unverified here**. No packages downloaded or installed.
