## Research and exact scope

The [official April2019 FFXII release article](https://na.finalfantasy.com/news/1079) supports configurable party automation and situational sets (FFXII-AI-2019 / FFXII-AI-01). Predicate choices come from Claude A1 and Hearthfall's existing simulation. No reference algorithm, asset or balance number copied. Weights1/3/10 and normal radii/maintenance conditions were read from existing code. The editor permits1–10 weighted demand, a scan no larger than the current skill's original condition and a0–100% reserve. These are player preferences, not new pacing targets.

Density/range overrides apply only to enemiesNear triggers; self-radius scaling and Rend's unbled filter remain. A retained range from a previous skill is bounded by the current skill. Buff/summon/channel families keep their existing trigger behavior. Elite presence means champion/rare/boss tiers1/2/4, excluding ordinary enemies and treasure goblins; it does not force the target selector. Original target ranges/LOS choices remain. Resource reserve is checked after the proposed spend, including each automatic channel tick. Gate failure ends an automatic channel through its existing recovery. Manual casting explicitly bypasses automatic conditions and retains normal costs/cooldowns/upkeep. Existing effects are not removed.

Strict command validation checks slot/skill intent, exactly supported fields, whole finite values and same-class buff identity. Self-buff dependency is rejected for new edits; a retained self-dependency after moving a skill is visible and clearable. The UI warns when a required buff is absent from the loadout. Apply sends one completed rule; Clear restores defaults. Fields, invalid state and controls use catalogue text. Save5/protocol8 prevent old code silently dropping spending restrictions. Missing legacy fields retain defaults; malformed present rules pause only affected automatic slots. No item/progression data discarded.
