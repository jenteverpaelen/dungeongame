# R-08 — Vampire Survivors and survivors-likes

Read 2026-10-09. L1 publisher evidence; game-feel claims remain unmeasured.

[VS-STORE](https://store.steampowered.com/app/1794680/Vampire_Survivors/) describes death-ending runs, gold-funded improvements between attempts, and refundable power-up purchases. The publisher's starter advice emphasizes focusing a few weapons. This supports a distinction between temporary run choices and persistent progression. The store is not evidence of a particular attack cadence, hit-stop implementation or retention effect.

**Inference for Hearthfall:** reversible build experimentation is worth evaluating within persistent characters. Copying a run reset would contradict the current character/save contract. Feedback should make automated attacks understandable without adding mandatory constant clicking. Keep current combat unchanged until effects and target readability have been observed.
