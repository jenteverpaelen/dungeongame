# Legends of Idleon — R-02, first evidence pass

Read 2026-10-09. Primary loop evidence L1; community progression detail L2/S2. Current build and offline formulas unresolved. [Source register](SOURCES.csv), claims IDLE-01–03.

## Findings

The [developer site](https://www.legendsofidleon.com/) and [publisher store](https://store.steampowered.com/app/1476970/IdleOn__The_Idle_RPG/) describe complementary characters performing combat, gathering and crafting, including progress while away. The store lists the full release as 2025-11-06. Neither read description establishes an exact offline cap, efficiency ratio or simulation implementation. Marketing uses classes and character counts inconsistently enough that those counts are excluded here. [S; IDLE-SITE/STORE]

[DigitalTQ's World 1 guide](https://www.digitaltq.com/wiki/idleon/world-1-guide-blunder-hills), dated 2026-04-07, and [a quest guide](https://idleon.guide/world-1-quests/) both place the class-choice NPC milestone at level 10. The latter sequences fighting, crafting/equipping, map travel and talent spending. This is secondary agreement with unknown source independence, not current-client verification. [S2; IDLE-W1/QUESTS]

## Application to Hearthfall [P]

A goal can teach an existing action and reward progress toward the next action. This suggests examining a small objective sequence around our existing combat/equipment/skill loop before creating more systems. An account-wide alt economy would be a much larger change: Hearthfall currently persists characters independently. Do not infer that Idleon's retention comes from alts or copy its monetization.
