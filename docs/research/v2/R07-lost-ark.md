# R-07 — Lost Ark

Read 2026-10-09. Partial L2, undated publisher guide. Rested activity rewards and offline production are different mechanisms.

[LA-GUARD](https://www.playlostark.com/en-gb/game/guide/guardian-raid-guide) describes a Guardian encounter entered solo or with up to four players, participant-scaled health/stagger, an entrance workshop for preparation, an entry requirement and limited daily reward collection. The page says missed daily collection contributes toward a later extra reward. These are guide-specific rules, not independently observed current numbers.

**Inference for Hearthfall:** clearly distinguish permission to enter an activity, permission to receive a reward, and party eligibility. Rest compensation could reduce pressure to log in daily, but this page provides no evidence that daily chores improve our game. Existing AFK rewards remain unchanged.
