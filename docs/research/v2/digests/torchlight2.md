# Torchlight II PC — decision digest

2026-10-09, C063. **PC base-game scope; not Torchlight Infinite, console updates or optional mods.** [Dossier](../R21-torchlight2.md), [claims](../CLAIMS.csv), [sampled frames](../TIMELINE-FRAMES.json).

**What the player decides.** Historical developer notes separate character-level ability access from bonuses at invested ranks. Editor documentation names character and fame point sources without supplying their values. Footage separates quest offer, progress, reward choice and the next offer. Inventory comparisons distinguish candidate/equipped items and item level from alternative requirements; pet and character inventories coexist, and transfer/sell/buy hints change with context (TL2-01, TL2-09, TL2-14, TL2-15, TL2-16, TL2-17).

**Useful pattern for Hearthfall [inference].** Judge a tier by what it does to play, not merely its rank number. Keep reward selection distinct from earning eligibility and claiming the result. Name an item's actual destination and the current operation. Save/restore must include the full ownership scope: official backup instructions distinguish character files and shared stash (TL2-05). That is a scope lesson, not an MMO storage design.

**Avoid transferring.** Rank5/10/15 is not character level and is not a Hearthfall target. Secondary PC sources report last-three-point refunds; a console potion update and a developer-attributed respec mod do not establish unrestricted base-PC refunds (TL2-03, TL2-04, TL2-08). Pet selling would change the frozen physical-service loop. New Game Plus is not proof of seasonal or online persistence (TL2-02).

**Still unknown.** Pinned final PC numerical tables and full point budget; exact current refund behavior; recording build/mod state; actual reward/equip/vendor operations; clean pace and loot rates. The developer's own loot study was provisional and condition-sensitive (TL2-12).

**Next action.** Retain the current skill/tier behavior audit; extend future objective tests through selected reward, full inventory, retry and restore. Keep content domains explicit without adopting a new editor pipeline solely from GUTS. No pet, fee, rank schedule or town-flow change is selected.
