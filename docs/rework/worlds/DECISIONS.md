# Worlds rebuild — decisions (what / why / evidence / rollback)

| # | Decision | Why / evidence | Rollback |
|---|---|---|---|
| D-W01 | Fields grow ≈ 2.2–2.5× linear (≈ 5–6× area), dungeons ≈ 2.2× | REFERENCES §1 (11–32 s of walking, 1.4–3.2 screens) vs §3 target 60–90 s from W2/W4/W5 | `ZONES[id].size` + the zone plan; ids unchanged so saves load either way |
| D-W02 | Whispering Glade and Ashen Hollow keep their generator this pass | They are the open farming fields the balance sim (`sim.ts leveling`) was calibrated on; rebuilding them changes the measured pace the owner just approved. They are not quest zones. | n/a |
| D-W03 | No new XP source. Side quests pay gold by the camp-contract formula; caches roll exactly one rare elite's drop; shrines give combat buffs only | BALANCE.md cut XP/loot on the owner's request; derived budgets (REFERENCES §3) | remove `pois` / side quests from the plans |
| D-W04 | Shrines: **Empowered** +25 % damage, **Frenzied** +25 % attack speed, **Keen** +10 % critical hit chance; 120 s, re-use refreshes instead of stacking; per character a shrine recovers after 3 min | W1 durations and kinds. The server buff record only carries damage / crit chance / crit damage / attack speed (`server/src/sim/types.ts` Buff), so Blessed and Fleeting have no clean mapping, and Enlightened (XP) / Fortune (magic find) would add XP and loot that BALANCE.md just removed | delete the `shrine` POIs |
| D-W05 | One additive export line at the end of `client/src/render/art/townScenery.ts` (the town's prop/decor painters) | reuse the approved town art instead of copying 400 lines; town behaviour unchanged | delete the export line and the zone renderer import |
| D-W06 | Dungeons may hold pre-placed packs that are not mechanism stages (`validateAdventures`: stage encounters ⊆ encounters instead of equal) | a 10-monster dungeon is not a dungeon; finite, no respawn, spawned when the instance starts | drop the `amb_*` encounters from dungeon plans and restore the equality check |
| D-W07 | Tests that hard-coded old coordinates now read positions from the zone data (contacts, portals, locations, walls) | the layouts moved; reading from data keeps the same assertions meaningful for any future layout | git history |
| D-W08 | Only Rillwake got a new side quest this pass; the other zones' optional layer is events, shrines, caches, named rares and secrets (DESIGN §2 lists the planned side quests, not delivered) | time box; a quest needs contacts, text in the cast's voice, validator and a test — better one complete than eleven thin | add more `WORLD_QUESTS` entries; contacts are cheap with the kit |
| D-W09 | Zone sizes stop at ≈ 2.2–2.5× linear even though the shortest crossings (33–65 s) sit below the 60–90 s target | the extra length would mostly be empty walking without more authored content; quest chains already walk further than the shortest crossing; frame time is the binding constraint (REFERENCES §4) | raise `ZONES[id].size` and the plan scale `S`; the kit re-dresses automatically |
| D-W10 | Ground chunk bake budget 4 → 3 ms per frame in zones (town untouched) | p95 frame time while walking (REFERENCES §4) | one constant in `zoneGround.ts` |
| D-W10 | Density is measured as "interior" items per screen (things standing on walkable floor, people, packs), not raw counts | raw counts flatter zones with edge decor; interior and sprite coverage matched the lead's visual verdict (LOG W4) | `scripts/density.ts` METRIC=total |
| D-W11 | Big landmarks are kit structures that slide clear of routes, contacts, portals, packs and each other (≤ 480 u) or are left out | keeps the validators green without hand-tuning every footprint | remove the `z.structure` lines |
| D-W12 | Side quests in all nine rebuilt field zones plus nine repeatable event contracts (supersedes D-W08); side quests add one magic class weapon, contracts pay gold only, no XP anywhere | the same reward kinds the story and Orren's contracts already use; gold from the camp-contract formula | drop entries from `WORLD_QUESTS` |
| D-W13 | The Pumpworks valve gallery has no solid dressing | the single-monster combat probes (reedclaw, siltusk) measure attacks on that open floor | set its `dress` back to 0.5+ and move the probes |
| D-W14 | Off-screen props are detached from the sorted entity layer | the per-frame depth sort only sees drawable props | re-add all props once |
| D-W15 | Prop textures paint at the scale rounded up to 0.25 and the sprite scales down | 719 textures / 120 MB per zone and 369 MB over all zones before, never released; ≤ 100 per zone after; shapes unchanged | key textures by exact scale again |
