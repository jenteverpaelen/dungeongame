## How to look at it (10 minutes)

1. Start the dev build: double-click `hearthfall-rework\.local\START-DEV-LINK.cmd`, open **http://localhost:2587/**.
   (It has the debug panel on: **F2** → "Full Set", "Legendaries", "Level +10" show gear and zones quickly.)
2. Pick a class, name your hero, enter. Press **O** (Settings → Display → *Interface size*, *Gear effects*), **I**, **K**,
   **P**, **J**, **,** (map), the HUD menu bar bottom right.
3. **Gear:** F2 → Full Set (or Legendaries) → look at your hero in town; **C** → *Gear showcase* shows the rank and what
   raises it next. Two browser windows on one server show the newcomer-vs-veteran difference side by side.
4. **Worlds:** Waypoint → *Rillwake Crossing* first (the quality bar), then Bracken Sluice … Hollowstar Array. Shrines and
   caches are the glowing stones and chests off the road; the world map's *This area* tab shows everything in a zone.
5. **Accounts** are off by default. To try them: `set ACCOUNTS=optional` (or `required`) before starting the server.

### Worlds (final state)

All 12 quest zones were rebuilt twice over (zone kit, then a density/landmark/content pass). Measured by
`scripts/density.ts` ("interior items per screen", town square = 100 %):

| | before | after (average) |
|---|---|---|
| Outposts (camps) | 8–33 % | 64–133 % (Beaconbreak 64 %, all others ≥ 82 %) |
| Wild regions | 11–16 % | 82–125 % |
| Route screens | 4–11 % | 46–105 % |
| Screens below 35 % | 24–53 per zone (all of them) | 4–19 per zone (bridges, long straight roads, boss rooms) |

* **Content:** side quests in all nine rebuilt field zones (collect, kill a named rare, interaction chains, field waves;
  gold + one magic class weapon on the one-time ones, no XP) plus nine repeatable event contracts; shrines, caches,
  named rares, secrets and events per zone. `server/test/worldQuests.test.ts` runs all 18 through the real command path.
* **Life and landmarks:** critters that react to you, residents/walkers, smoke/embers/lights, and big authored structures
  (towers, windmill, kiln stacks, wrecks, pump engines) that slide clear of routes, contacts and packs.
* **Frame time while walking** (main-thread work p95, 1920×1080): 10–17 ms across the 12 zones (Cinderwash 16.9 and
  Sablefen 17.2 are slightly over 16.7; the rest are under). 30-hero channel in Rillwake: p95 18–20 ms client, server
  tick 2.8–5.1 ms average. Prop textures no longer leak (369 MB → ~36 MB over all zones).
* **Not done:** crowd benchmark for the other zone types; the area map does not yet draw roads/water per zone; evidence
  shots with monsters for every zone; the minimap and HUD repaint cost every frame (the biggest remaining perf lever).
  Whispering Glade and Ashen Hollow are intentionally unchanged.

## Known gaps (honest list)

* **Human feel is unverified.** Balance came from bots that stand still in melee; nobody has played the new numbers.
* **Class spread:** warrior is weakest, ranger/mage strongest (2–3× in fitted factors). A class damage pass is not done.
* **Torment ladder is compressed** (a set-and-legendaries kit clears Torment I–III quickly); paragon growth was not modelled.
* **Gold and vendor prices** were not retuned; check the economy audit before a public test.
* **Zone frame time while walking** can exceed 16.7 ms in some zones (ground chunks paint on demand); dungeons are thinner
  than fields; Whispering Glade and Ashen Hollow are unchanged (the balance was calibrated on them).
* **Crowds:** 100 never-seen looks arriving at once show class placeholders for 20–30 s instead of freezing.
* **Accounts:** no email recovery, sessions end at server restart, no deletion/export flow, and the roadmap asks for an
  independent review of the auth code before any public test.
* **The owner's own playtest server (:2577) was not running** when I looked and was never touched; its saves are intact.
  The stray empty `hud.css` in the main checkout is harmless (delete it if you like).
